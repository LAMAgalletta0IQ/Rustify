# `src-tauri/capabilities/default.json`

**Module:** [[tauri-config]] · **Language:** JSON

## Purpose

Tauri 2's permission grant for the main window. Declares which built-in and
plugin APIs the **frontend** may invoke over IPC.

## Contents

```json
{
  "$schema": "../gen/schemas/desktop-schema.json",
  "identifier": "default",
  "description": "Capabilities for the main window.",
  "windows": ["main"],
  "permissions": [
    "core:default",
    "core:event:default",
    "core:window:allow-start-dragging",
    "opener:default"
  ]
}
```

## Key items

| Permission | Grants |
| --- | --- |
| `core:default` | The baseline Tauri set, including `invoke` |
| `core:event:default` | `listen` / `emit` — required by [[store.svelte.ts]] |
| `core:window:allow-start-dragging` | Dragging the window by a custom region |
| `opener:default` | The opener plugin's frontend API |

`"windows": ["main"]` targets the unlabelled window from
[[tauri.conf.json]], which Tauri names `main` by default.

`$schema` points into `gen/schemas/`, generated by [[build.rs]] — which is why
the reference resolves only after a build.

## Inputs / outputs / side effects

Read by [[build.rs]] at compile time; compiled into the binary's ACL. Not read
at runtime.

## Dependencies

**Read by:** [[build.rs]]
**Affects:** [[store.svelte.ts]] (events), any frontend plugin call

## Notable logic / gotchas

> **Capabilities gate the *frontend* IPC surface only.** Rust-side plugin usage
> is ungated — which is why [[media_keys.rs]] uses the global-shortcut plugin
> with **no** entry here. Adding `global-shortcut:default` would only be needed
> if the frontend called that plugin directly.

- **Removing `core:event:default` breaks the UI silently.** `listen()` would
  reject, [[store.svelte.ts]] would never receive `playback:changed`, and the
  interface would simply stop updating — with no obvious error.
- **`#[tauri::command]`s are not individually gated.** `core:default` covers
  `invoke`; the app's own 32 commands need no per-command permission.
- The permission set is intentionally minimal — no filesystem, shell, HTTP or
  dialog access is granted to the webview.
