# `.gitignore`

**Module:** [[project-root]] · **Language:** gitignore

## Purpose

Declares which paths git should ignore. The repository was initialised with a
single `Initial commit` (`7d31caf`), and this file was present from the start —
so none of the ignored build output was ever committed.

## Contents

```gitignore
node_modules/
dist/
src-tauri/target/
src-tauri/gen/
.vscode/
*.log

# Local Spotify credentials + audio cache written at runtime.
src-tauri/.cache/

# Local config. `.env.example` is the committed template.
.env
```

## Key items

| Pattern | Why |
| --- | --- |
| `node_modules/` | npm dependencies; restored from [[package-lock.json]] |
| `dist/` | Vite output; regenerated by `npm run build` |
| `src-tauri/target/` | Cargo build output, including the release binary |
| `src-tauri/gen/` | Tauri-generated schemas from [[build.rs]] |
| `.vscode/` | Editor settings |
| `*.log` | Stray log files |
| `src-tauri/.cache/` | **Runtime secrets** — librespot credentials and audio cache |
| `.env` | Local config; `.env.example` is the committed template. See [[build-and-config]] |

The ignore list closely matches what this vault excludes; see [[excluded]].

## Inputs / outputs / side effects

None at build or runtime. Consumed only by git.

## Dependencies

**Related to:** [[.gitattributes]], [[excluded]], [[build-and-config]]

## Notable logic / gotchas

- **`src-tauri/.cache/` is the security-relevant entry.** librespot writes
  cached credentials there. Committing it would publish account access.
- **`.env` is ignored for tidiness, not secrecy.** It holds a Spotify **Client
  ID**, which is not a secret — it travels in the clear in every OAuth redirect
  and appears in ncspot's source. This flow is PKCE and uses no client secret.
  The entry keeps a per-developer value out of shared history.
- **Lockfiles are deliberately *not* ignored.** [[Cargo.lock]] and
  [[package-lock.json]] are committed because this is an application, not a
  library — and [[Cargo.lock]] carries the load-bearing `vergen` pin.
- **`app-icon.png` is not ignored** — [[app-icon.png]] is a source asset, while
  its generated output in [[icons]] is committed too (Tauri expects
  `icons/icon.ico` to exist at build time).
- The real runtime data path is the Tauri app data directory, not
  `src-tauri/.cache/`; that entry guards against an older or dev-mode layout.
