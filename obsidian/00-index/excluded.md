# Excluded from this vault

Nothing was skipped silently. Every path below is deliberately undocumented,
with the reason given. Everything else in the repository has a note — see
[[MOC]].

## Directories excluded entirely

| Path | Files | Reason |
| --- | --- | --- |
| `node_modules/` | ~52 packages | Third-party npm dependencies. Not project source; reinstallable from [[package-lock.json]]. The dependencies that matter are documented in [[external-dependencies]]. |
| `src-tauri/target/` | thousands | Cargo build output (compiled artifacts, incremental cache, the release `.exe`). Regenerated by `cargo build`. |
| `dist/` | 3 | Vite production bundle (`index.html` + hashed JS/CSS). Regenerated by `npm run build`; embedded into the binary at compile time. See [[build-and-config]]. |
| `src-tauri/gen/schemas/` | 4 | Tauri-generated ACL/permission JSON schemas (`acl-manifests.json`, `capabilities.json`, `desktop-schema.json`, `windows-schema.json`). Written by `tauri-build` on every build from [[default.json]] — that hand-written file is the real source and *is* documented. |
| `obsidian/.obsidian/` | ~12 | This vault's own Obsidian app settings and community plugins. Editor configuration, not project code. |

Note: this project is **not** a git repository, so there is no `.git/` to
exclude. [[.gitignore]] exists in anticipation of one and is documented.

## Binary assets summarised rather than documented individually

| Path | Files | Reason |
| --- | --- | --- |
| `src-tauri/icons/**` | 57 | Every file is a raster/vector icon generated by `npm run tauri icon` from a single source image. They carry no independently readable logic, and 57 near-identical notes would add noise to the graph without adding understanding. Covered collectively by [[icons]], which lists every file and explains which platform consumes each. The human-authored source image, [[app-icon.png]], has its own note. |

## Files documented despite being generated

Two lockfiles are machine-written but are **not** excluded, because each
encodes a decision a reader must know about:

- [[Cargo.lock]] — pins `vergen` to 9.0.6. Without that pin the project does
  not compile at all. See [[build-and-config]].
- [[package-lock.json]] — records the `allowScripts` approval for `esbuild`,
  without which Vite cannot build.
